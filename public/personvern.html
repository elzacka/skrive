Kort oppsummert

Notatene dine lagres kryptert på enheten din, og Skrive sender dem aldri til noen server.

Hva som lagres

  • Notater og mapper: Lagres lokalt i nettleseren din, kryptert med AEGIS-256.
  • Innstillinger: Språkvalg og visningsinnstillinger lagres lokalt.
  • Auto-backup: Hvis aktivert, lagres en kryptert kopi av notatene til en lokal mappe du velger selv. Kopien er beskyttet med en passordfrase du velger, og filen forlater aldri enheten din.

Hva som ikke skjer

  • Notatene dine sendes ikke til servere eller tredjeparter.
  • Ingen informasjonskapsler (cookies) brukes.
  • Ingen brukerkontoer eller innlogging kreves.

GitHub

Skrive ligger på GitHub Pages. GitHub lagrer IP-adressen din av sikkerhetshensyn når du åpner appen. Les mer i GitHubs personvernerklæring

Kryptering

Alle notater krypteres med AEGIS-256 (eller XChaCha20-Poly1305 som fallback) før nettleseren din lagrer dem. Krypteringsnøkkelen genereres og lagres lokalt på enheten din.

Rettighetene dine

Notatene dine lagres lokalt på enheten din, så du har full kontroll over dem. Du kan:

  • Eksportere alle data via Eksporter-funksjonen. Filer du eksporterer selv, er ukrypterte, og du velger selv hvor de lagres.
  • Slette all data ved å tømme nettleserens lagring. Du må også slette backupfilen i mappen du valgte hvis du har aktivert auto-backup.
  • Bruke appen uten internettilkobling.
